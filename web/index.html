How it works

hart emulates a single-core 64-bit RISC-V computer. The CPU, Sv39 MMU, PMP, a soft-float FPU, and the CLINT, PLIC, 16550 UART, and power-off devices are all written from scratch in Rust, then compiled to WebAssembly.

It runs in a Web Worker in this tab and boots unmodified upstream guest software: OpenSBI 1.8 firmware, a Linux 6.18 LTS kernel, and a BusyBox shell. Nothing is sent to a server.

How it was validated

  • riscv-tests: all 134 of 134 rv64 ui, um, ua, uc, uf, ud, mi, and si tests pass.
  • riscv-arch-test (ACT4): all 592 of 592 tests generated for hart's configuration pass, interrupts included, against expected results from the Sail reference model (39 Sv48 tests excluded: hart implements Sv39 only).
  • Berkeley TestFloat: 33.2 billion vectors for add, subtract, multiply, divide, square root, fused multiply-add, comparisons, and conversions, in all five rounding modes, with no mismatch in results or exception flags.
  • Spike: per-instruction commit logs match the reference simulator for 2,000 randomized programs and for the Linux boot, instruction by instruction, from reset through the shell prompt (150 million instructions).
  • Boot tests: natively and on this page, Linux boots to the shell and a fixed command script produces the expected output. Headless Chromium reaches the prompt in a median of 1.15 s over 5 runs on a 4-vCPU machine, served locally; Firefox passes too.

Results for commit 3f756f9. The evidence and the commands to rerun each check are in the README.

Build it yourself

git clone https://github.com/theoi/hart.git
cd hart && cargo build --release
gh release download guest-v1 -R theoi/hart \
  -p fw_jump.bin -p Image -D images
target/release/hart --images images

guest/build.sh builds the guest images from pinned upstream sources with no source patches. The guest-v1 release has the images, their checksums, and the complete corresponding source and license notices (legal-info.tar).
